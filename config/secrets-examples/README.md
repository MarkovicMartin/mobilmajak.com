# Šablony secrets (v gitu)

Složka `secrets/` je **celá v gitignore** – sem patří jen necitlivé příklady.

| Soubor | Zkopírovat do |
|--------|----------------|
| `mobilmajak-finance.example.json` | `secrets/mobilmajak-finance.json` |
| `mobilmajak-slack.example.json` | `secrets/mobilmajak-slack.json` |
| `mobilmajak-symplio.example.json` | `secrets/mobilmajak-symplio.json` |

Návod k nastavení: [`docs/secrets-setup.md`](../docs/secrets-setup.md)
